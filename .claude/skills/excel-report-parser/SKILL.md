# Excel 业务报表解析与分析 Skill

## 目标

读取一份或两份 Excel 业务报表，理解其结构（标题行、多层表头、层级数据行、汇总行、
多 Sheet 等），完成数据分析或期间对比，生成结构化摘要，并支持用户追问。

---

## 步骤总览

按顺序完成以下任务，用 TodoWrite 追踪进度：

1. 收集必要信息
2. 安装/确认依赖
3. 解析 Excel 文件
4. 理解报表结构
5. 执行分析（单份 or 对比）
6. 生成摘要报告
7. 支持追问

---

## Step 1 — 收集必要信息

向用户确认以下内容（已提供的跳过）：

- **文件路径**：一份（分析）或两份（对比）Excel 文件的完整路径。
  Windows 路径示例：`C:\Reports\2024Q4.xlsx`
- **分析模式**：单份分析 / 两期对比
- **关注 Sheet**：若不指定则分析全部 Sheet 或第一个 Sheet
- **关注指标**：用户最关心哪些列（如余额、增速）；如不指定则分析所有数值列
- **期间标签**（对比模式）：如"2024年12月"、"2025年3月"
- **业务背景**（可选）：如"这是零售银行存款报表，单位万元"
- **知识库文件**（可选）：如有先验分析规则或业务词典，提供路径

收集完毕后继续，无需等用户再次确认。

## Step 2 — 安装/确认 Python 依赖

运行以下命令检查并安装依赖：

```bash
python -c "import openpyxl, pandas" 2>nul || pip install openpyxl pandas -q
```

Windows 下若 `python` 不可用，尝试 `python3`。

---

## Step 3 — 解析 Excel 文件

使用项目内置解析脚本 `.claude/scripts/excel_parser.py`。

### 3a. 单份分析

```bash
python .claude/scripts/excel_parser.py "<文件路径>" \
  --output markdown \
  --max-rows 300
```

若需指定 Sheet：加 `--sheet "<Sheet名>"`

### 3b. 两期对比

```bash
python .claude/scripts/excel_parser.py "<文件A路径>" "<文件B路径>" \
  --output markdown \
  --period-a "<期间A标签>" \
  --period-b "<期间B标签>" \
  --top 15
```

若需指定行键列（第一列非默认）：加 `--key-col "<列名>"`

### 3c. 获取 JSON（结构调试）

```bash
python .claude/scripts/excel_parser.py "<文件路径>" --output json
```

> 若脚本路径不对，先确认项目根目录：`pwd`（Linux）或 `cd`（Windows CMD）

## Step 4 — 理解报表结构

读取解析输出后，**在回复中显式说明你的理解**，包括：

```
报表结构理解：
- Sheet 名称：XXX
- 报表标题：XXX（第 N 行，合并居中）
- 列表头层次：共 N 层，示例：产品大类 / 余额、增速
- 数据行数：N 行
- 行层级说明：
    - 第1行"全国"为汇总，下接"其中：华东"等子行（level=1）
    - 最后一行"合计"为总汇总行
- 单位/业务背景：[用户提供 or 从表头推断]
```

如发现解析异常（如合并单元格识别偏差、数值列为文本），记录并告知用户，
然后尝试用 JSON 模式再次解析调试。

## Step 5 — 执行分析

### 5a. 单份报表分析

根据解析结果完成以下分析（可用 Python 脚本辅助，也可直接基于 JSON 用代码分析）：

**分布分析**
- 各行占总量的比例（排名前 N 的行）
- 数值最大/最小的行
- 是否存在占比超过 50% 的单一行

**层级分析**
- 对每个"整体"行，列出其子行分布
- "其中"各子项占比

**异常发现**
- 子项之和是否与汇总行吻合（校验数据完整性）
- 是否有缺失值

**输出格式**（Markdown）：
```
## 分布分析 — [指标名]
- 第1名：[行名] [值] ([占比]%)
- ...
## 层级结构
...
## 数据质量提示
...
```

### 5b. 两期对比分析

基于 `changes_to_text` 输出 + 额外推断：

**必做**
- 列出绝对变动最大的 Top N 行（每个数值列）
- 列出相对变动（百分比）最大的 Top N 行（排除汇总行避免双计）
- 说明整体（汇总行）变动情况

**推断性发现（大模型判断）**
- 变动是否集中在某一类别（如某地区、某产品线）
- 变动方向是否一致（全面上升/下降 vs 分化）
- 是否有逆势变动的行（多数上升但某行下降）
- 排名变化（期初 Top3 vs 期末 Top3）

**先验规则**（如用户提供了业务背景）
- 结合业务背景解读变动原因（如季节性、政策因素）

**输出格式**：
```
## 对比概览 — [Sheet名] [期间A] vs [期间B]
- 整体变动：[汇总行指标] A→B，变动 X（Y%）

## 变动最大项（[指标名]）
1. [行名]：A → B，+X（+Y%）
...

## 大模型发现
- ...

## 业务解读（基于背景知识）
- ...
```

## Step 7 — 支持追问

摘要生成后，**主动告知用户**可以继续提问，例如：

> "摘要已生成。您可以继续提问，例如：
> - '帮我看看华东区的具体变动'
> - '哪些产品的增速连续两期为负？'
> - '对比一下 A 产品和 B 产品的趋势'
> - '数据里有没有和汇总行对不上的情况？'"

对每个追问，按以下流程处理：

1. 判断是否需要重新运行解析器（通常不需要，JSON 已在 context 中）
2. 若需要新计算，写一个临时 Python 脚本执行后删除
3. 结合业务背景回答，引用具体数据

## 附录 B — 常见报表结构处理指南

### 多层表头（2~3 层）
解析器会自动用 `/` 拼接，如 `产品 / 余额（亿元）`。
若拼接不准确，可在 `--output json` 模式下查看 `col_headers` 字段核对。

### "其中"层级行
解析器通过 `_level` 字段标注（0=顶层，1=其中子行）。
分析时，子行不参与全局排名，仅在本组内排名。

### 多汇总行（分组汇总）
识别 `_is_summary=true` 的行，对比时自动排除，避免重复计算。

### 合并居中数值
openpyxl 的 `data_only=True` 会读取缓存值；若值为 None，说明文件从未被 Excel 打开计算过，提示用户先用 Excel 打开并保存。

### 多 Sheet 同格式报表
若用户要求跨 Sheet 汇总，循环调用解析器各 Sheet 后，用 Python 合并 `rows` 列表再分析。

## 附录 C — 业务知识库使用

若用户提供了业务知识库文件（txt/md/json）：

1. 使用 Read 工具读取文件内容
2. 将关键词典、指标定义、行业基准嵌入分析提示
3. 在"业务解读"章节引用知识库内容并注明来源

若无知识库，从报表本身推断：
- 从表头推断单位（如"（万元）"、"（%）"）
- 从行名推断业务含义（如"对公存款"、"个人贷款"）

## 注意事项

- Windows 路径中反斜杠需转义：`C:\\Reports\\file.xlsx` 或用正斜杠 `C:/Reports/file.xlsx`
- 文件路径有空格时用引号包裹
- 若文件有密码保护，告知用户需先解除密码
- 超大文件（>10万行）建议先用 `--max-rows` 限制输出，避免 context 溢出
- 不要在摘要中捏造数据；如解析结果不确定，明确标注"待核实"
