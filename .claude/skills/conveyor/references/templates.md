# Conveyor 控制文件与交付物模板

以下模板按需复制使用。`<尖括号>` 内为占位符；表格列可按任务增删，
但**ID、状态、完成时间三列不可省略**。

---

## 1. `01_任务计划.md` 模板（任务定义 + SOP）

```markdown
# 任务计划：<任务名>

## 任务定义
> 每个要素标注来源（来源：用户指定 / 默认 / 推断）——见阶段 0 提问规则；
> "推断"的要素须在首次汇报和汇总报告中显著提示

- 循环项：客户（来源：用户指定）
- ID 字段：客户号（形如 C0012；数据中字段名为"客户编码"）（来源：推断）
- 清单来源：扫描 `./客户资料/` 下的一级子目录（来源：用户指定）
- 每项输入与阅读顺序：（来源：用户指定）
  1. `基本信息.md` —— 必读，先读
  2. `交易流水.xlsx` —— 必读，后读
  3. `补充材料_*.pdf` —— 可选，最后读
- 处理流程概述：读取输入 → 提取关键信息 → 按评分规则打分 → 产出分析报告（来源：用户指定）
- 交付物定义（验收标准）：（来源：智能体提议，用户已确认）
  - `<ID>_分析报告.md`：必须包含【基本情况】【风险点】【评分（1~5）】【依据引用】四节
- 输出位置：`./客户分析结果/`（来源：用户指定）
- 成果打包：核对通过后，将 `交付/` + 汇总报告打包为
  `客户分析_交付_<YYYYMMDD>.zip`（来源：默认）
- 异常边界：（来源：用户指定）
  - 缺基本信息 → 跳过该客户
  - 缺交易流水 → 部分完成（只做定性分析，不打分）
  - 多出预期外文件 → 读取并在报告"附注"节说明
- 处理顺序：按客户号升序（来源：用户指定）
- 汇报节奏：每完成 1 项汇报一行（来源：默认）

## 单项标准流程（SOP）
> 由试跑第一项后固化；每次修改须在版本记录中登记

1. 创建 `交付/<ID>_<短名>/`（已存在则先清空——说明是中断重做）
2. 读 `基本信息.md`，提取：名称、行业、规模、成立年限
3. 读 `交易流水.xlsx`，计算：月均流水、最大单笔、异常交易笔数
4. 按评分规则打分：<规则明细>
5. 写 `<ID>_分析报告.md`（按交付物定义四节），文件头填元信息（见模板 5）
6. 自检后更新状态清单

## SOP 版本记录
- v1 <日期> 基于试跑项 C0012 固化，用户已确认
```

## 3. `03_异常记录.md` 模板（不同构情况登记簿）

```markdown
# 异常记录：<任务名>

> 每发现一个不同构情况立即追加一条；**无论是否处理过都必须记**

| 时间 | 循环项ID | 发现的情况 | 采取的动作 | 级别 | 对结果的影响 |
|---|---|---|---|---|---|
| 07-08 10:45 | C0015 | 缺少交易流水.xlsx | 只做定性分析，标部分完成 | ②跳过/部分完成 | 报告无评分节 |
| 07-08 11:02 | C0019 | 多出"诉讼记录.pdf"（不在预期结构中） | 已读取并在报告附注节引用 | ①可自行处理 | 报告多一节附注 |
| 07-08 11:20 | — | 目录中发现重复客户号 C0021（两个文件夹） | 暂停循环，等待用户指示 | ③暂停询问 | 循环暂停 |
```

## 5. 交付物文件头元信息模板

每个交付物文件（Markdown 放文件头，HTML 放 `<head>` 内注释）都要带：

```markdown
---
循环项ID: C0012
循环项名称: 张三公司
输入来源: 客户资料/C0012/基本信息.md; 客户资料/C0012/交易流水.xlsx
依据SOP版本: v1
生成时间: 2026-07-08 10:32
---
```

## 6. 链接类交付物 `<ID>_链接.md` 模板

交付物是在线页面等无法装进 zip 的形态时，在该项目录放此文件占位：

```markdown
---
循环项ID: C0086
循环项名称: 钱七网络
交付形态: 在线页面（链接类）
生成时间: 2026-07-08 15:20
---

- 页面地址：https://<平台生成的页面地址>
- 内容说明：该客户的风险分析可视化页面，含评分与依据图表
- 注意：页面托管在平台侧，zip 内仅含本说明文件
```

## 7. 消息内清单快照模板（无文件系统时的降级方案）

平台没有文件系统时，**每次回复末尾**附上完整快照，下一轮从最近的快照恢复：

```
—— Conveyor 清单快照 [4/12] ——
✅ C0012 张三公司 | ✅ C0013 李四商贸 | ⏭️ C0015 王五实业(缺流水,部分完成)
▶️ C0016 赵六贸易(处理中) | ⬜ C0017 | ⬜ C0018 | ⬜ C0019 | ⬜ C0020 …
异常：C0015 缺交易流水 → 部分完成，已记录
```

图例：`✅ 已完成　⏭️ 跳过/部分完成　▶️ 处理中　⬜ 待处理`
