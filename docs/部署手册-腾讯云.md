# 守明 · 腾讯云服务器部署手册

> 适用场景：腾讯云轻量应用服务器（Lighthouse）或 CVM，通过公网 IP 或自定义域名访问
> 预计耗时：45-60 分钟

---

## 准备工作

**服务器选型推荐**
- 腾讯云轻量应用服务器（Lighthouse）2核2GB 起步（月约 40-60 元）
- 系统镜像：**Ubuntu 22.04 LTS**（推荐）或 Ubuntu 20.04
- 带宽：1-5Mbps（个人使用完全够用）
- 磁盘：≥ 20GB SSD

**账号/资源准备**
- 腾讯云账号（已实名认证）
- SSH 登录密钥（在控制台创建并下载 .pem 文件）
- AI API Key（DeepSeek / 通义千问 / Anthropic 任选一）
- （可选）已备案的域名，用于 HTTPS

---

## 第一步：安全组配置

在腾讯云控制台 → 轻量应用服务器 → 防火墙（或 CVM 的安全组），添加以下规则：

| 协议 | 端口 | 来源 | 说明 |
|------|------|------|------|
| TCP | 22 | 你的本机 IP | SSH 登录（建议限制来源 IP） |
| TCP | 80 | 0.0.0.0/0 | HTTP（Nginx 入口） |
| TCP | 443 | 0.0.0.0/0 | HTTPS（可选，有域名时开启） |

> **注意**：不要直接开放 3001 / 4000 端口到公网，统一通过 Nginx 反代。

---

## 第二步：SSH 登录服务器

**本地终端执行：**

```bash
# 修改密钥文件权限（macOS / Linux）
chmod 400 ~/Downloads/your-key.pem

# SSH 登录（替换为你的服务器公网 IP）
ssh -i ~/Downloads/your-key.pem ubuntu@你的服务器IP
```

---

## 第三步：安装基础环境

登录服务器后，执行：

```bash
# 更新系统包
sudo apt update && sudo apt upgrade -y

# 安装必要工具
sudo apt install -y git curl wget nginx

# 安装 nvm（Node 版本管理器）
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.7/install.sh | bash

# 重新加载 shell 配置
source ~/.bashrc

# 安装 Node.js LTS
nvm install --lts
nvm use --lts

# 验证安装
node --version   # 应显示 v20 以上
npm --version

# 安装 PM2 和 serve
npm install -g pm2 serve
```

## 第五步：配置环境变量

```bash
# 复制配置模板
cp backend/.env.example backend/.env

# 生成随机会话密钥
node -e "console.log('SESSION_SECRET=' + require('crypto').randomBytes(32).toString('hex'))"
# 复制输出的整行

# 编辑配置文件
nano backend/.env
```

在 nano 编辑器中修改：

```bash
# 粘贴刚才生成的 SESSION_SECRET
SESSION_SECRET=你刚才生成的随机字符串

# 选择 AI 提供商（推荐 DeepSeek，境内直连）
AI_PROVIDER=deepseek
AI_API_KEY=sk-你的DeepSeek密钥
AI_MODEL=deepseek-chat

# 修改端口（保持默认即可）
PORT=3001

# Ctrl+O 保存，回车，Ctrl+X 退出
```

## 第七步：构建前端

```bash
cd ~/shoumingapp

npm run build --prefix frontend

# 验证构建成功
ls frontend/dist/
# 应看到 index.html 和 assets/ 目录
```

## 第八步：用 PM2 启动服务

```bash
cd ~/shoumingapp

# 启动后端（端口 3001，仅本地监听）
pm2 start backend/server.js --name shoumingapp-api

# 启动前端静态服务（端口 4000，仅本地监听）
pm2 start "serve frontend/dist -p 4000 -s" --name shoumingapp-web

# 查看状态（两个服务都应显示 online）
pm2 status

# 保存进程列表
pm2 save

# 设置开机自启
pm2 startup
# 执行命令输出的那行 sudo env PATH=... 命令
```

---

## 第九步：配置 Nginx 反向代理

```bash
# 创建 Nginx 配置文件
sudo nano /etc/nginx/sites-available/shoumingapp
```

粘贴以下内容（替换 `你的服务器IP或域名`）：

```nginx
server {
    listen 80;
    server_name 你的服务器IP或域名;

    # 前端静态文件
    location / {
        proxy_pass http://127.0.0.1:4000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;

        # PWA 缓存控制
        add_header Cache-Control "no-cache, no-store, must-revalidate" always;
    }

    # 后端 API
    location /api/ {
        proxy_pass http://127.0.0.1:3001;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;

        # 上传大小限制
        client_max_body_size 1m;
    }
}
```

```bash
# 启用配置
sudo ln -s /etc/nginx/sites-available/shoumingapp /etc/nginx/sites-enabled/

# 删除默认配置（避免冲突）
sudo rm -f /etc/nginx/sites-enabled/default

# 测试配置语法
sudo nginx -t

# 重启 Nginx
sudo systemctl restart nginx

# 设置 Nginx 开机自启
sudo systemctl enable nginx
```

**验证：** 浏览器打开 `http://你的服务器IP`，应看到守明登录页。

## 第十步：创建第一个账户

1. 浏览器打开 `http://你的服务器IP`
2. 点击「首次使用？创建账户」
3. 填写名字、用户名、PIN码（4-6位数字）
4. 登录成功即完成部署

## 可选：配置 HTTPS（需要已备案域名）

**前提：** 域名已解析到服务器 IP，且已备案（境内服务器要求）。

```bash
# 安装 Certbot
sudo apt install -y certbot python3-certbot-nginx

# 申请证书（替换为你的真实域名）
sudo certbot --nginx -d yourdomain.com

# 按提示输入邮箱，同意条款，选择是否强制跳转 HTTPS（建议选 2）
```

Certbot 会自动修改 Nginx 配置，完成后访问 `https://yourdomain.com` 验证。

**证书自动续期（已内置，验证即可）：**

```bash
sudo certbot renew --dry-run
```

## 常见问题

**浏览器打开 IP 没反应？**
1. 确认安全组已放开 80 端口
2. `sudo systemctl status nginx` 检查 Nginx 是否运行
3. `pm2 status` 确认两个服务都是 online

**Nginx 报 502 Bad Gateway？**
- 后端未启动：`pm2 restart shoumingapp-api`
- 端口冲突：`lsof -i :3001` 检查端口占用

**AI 教练没有回应？**
1. 检查 `backend/.env` 中 `AI_API_KEY` 是否正确
2. `pm2 logs shoumingapp-api` 查看错误详情
3. 境内服务器访问 DeepSeek API 无需代理，直接可用

**证书过期警告？**
```bash
sudo certbot renew
sudo systemctl reload nginx
```

**重启服务器后服务没有自动启动？**
重新执行 `pm2 startup` 输出的那行 sudo 命令，然后 `pm2 save`。
